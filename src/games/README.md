# เพิ่มมินิเกม

1. สร้าง React component ของเกมแยกจาก App.jsx เช่น src/components/PuzzleGame.jsx
2. เพิ่มรายการใน catalog.js: id ไม่ซ้ำและไม่เปลี่ยนภายหลัง, title, description, icon, enabled
3. เพิ่ม component ใน components.js โดยใช้ id เดียวกัน เมนูเลือกเกมจะปรากฏเมื่อมีเกมเปิดมากกว่าหนึ่งเกม
4. เกมได้รับ active (กำลังแสดงหรือไม่) และ onHatched (ใช้เฉพาะเกมฟักไข่เพื่อแจ้งสถานะสัตว์)
5. ค่าเริ่มต้นเกมที่ไม่เลือกจะ unmount ต้องคืน timer, subscription, event listener ใน cleanup และบันทึกคิวที่ยังไม่ส่งก่อนออก
6. keepMounted=true ใช้เฉพาะเกมที่ต้องรักษาการเชื่อมต่อแม้ซ่อนอยู่ เกมฟักไข่ต้องคงไว้เพื่อติดตามการปลดล็อกสัตว์และส่งคิวค้าง เกมอื่นควรหยุดเสียง/animation/polling เมื่อ active=false
7. เกมใหม่ใช้ gameStorageKey(id, version) แยกข้อมูล ห้ามเปลี่ยน key ของเกมฟักไข่เดิมหรือย้ายยอดเดิมโดยไม่มี migration
8. ยอดเกมใหม่ที่รวมทุกคนต้องมีตาราง/RPC/Realtime แยกชัดเจน พร้อมจำกัด batch, ป้องกันนับซ้ำ และทดสอบโควต้า ห้ามนำยอดเกมไปเพิ่มยอดโดเนท

แต่ละเกมมี error boundary ของตัวเอง จึงไม่ทำให้ทั้งเว็บหยุดแสดงผลเมื่อเกิด render error ไม่มีเกมตัวอย่างหรือเกมที่ยังใช้ไม่ได้แสดงให้ผู้เล่นเห็น
