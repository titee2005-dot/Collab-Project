# เพิ่มมินิเกม

ปุ่มมินิเกมบนหน้าหลักเปิด Modal เลือกเกมแบบเดิม แต่การ์ดเกมแต่ละใบเป็นลิงก์ไปหน้าเล่นเต็มหน้าที่ /games/:id เช่น /games/hatching ส่วน /games ยังคงเป็นหน้าเลือกเกมสำรองและใช้เป็นทางกลับจากหน้าเล่น

1. สร้าง React component ของเกมแยกจาก App.jsx
2. เพิ่ม id, title, description, icon, enabled ใน catalog.js
3. ลงทะเบียน component ด้วย id เดียวกันใน components.js หน้าเลือกเกมและเส้นทางจะรองรับอัตโนมัติ
4. เกมที่ไม่ถูกเลือกจะไม่ mount ต้องคืน timer/subscription ใน cleanup และบันทึกคิวก่อนเปลี่ยนหน้า
5. ใช้ gameStorageKey(id, version) สำหรับเกมใหม่ ห้ามเปลี่ยน key เกมเดิมหรือย้ายยอดโดยไม่มี migration
6. เกมใหม่ที่รวมยอดทุกคนต้องมีตาราง/RPC แยก จำกัด batch และป้องกันนับซ้ำ ห้ามเพิ่มยอดโดเนทจากยอดเล่นเกม

หน้าห้องใช้ HatchingPair แบบ headless เพื่อดูสถานะสัตว์และส่งคิวคลิกที่ค้าง ไม่มี UI เกมซ่อนใน dialog หน้า /games เป็นรายการอย่างเดียว ไม่มี subscription เกม หน้า /games/hatching ใช้ฐานข้อมูลและ sessionStorage ชุดเดิม ยอดที่เซิร์ฟเวอร์ยืนยันอยู่ครบ

ทดสอบเปิดลิงก์ตรง รีเฟรช ย้อนกลับ และ /games/id ที่ไม่มีอยู่ก่อนเผยแพร่ Vercel ใช้ SPA rewrite ที่มีอยู่เพื่อรองรับลิงก์ตรง
